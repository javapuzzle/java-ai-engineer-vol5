# ☕ Java AI Engineer — Volume 5 Code Repository

This repository contains the complete, compilable source code for **Volume 5** of the [Java AI Engineer](https://javapuzzle.com) series.

## 📁 Repository Structure

`
├── pom.xml                 # Root Maven parent / aggregator
├── chapter-01/             # Hands-on code & unit tests
├── chapter-02/
...
└── chapter-20/
`

## 🛠️ Prerequisites

- **Java 21+** (OpenJDK recommended)
- **Maven 3.9+**

## 🚀 Building & Running

To build all chapters from root:
`ash
mvn clean install
`

Or step into any chapter folder:
`ash
cd chapter-01
mvn test
`
